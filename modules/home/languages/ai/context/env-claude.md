# Environment

`~/.claude/` is generated by nix from `~/.config/home-manager` - see
`modules/home/languages/ai.nix` and the docs it reads under
`modules/home/languages/ai/`. `CLAUDE.md`, `settings.json`, `rules/`, and most
of `skills/` are read-only `/nix/store` symlinks, so editing them in place
fails or is silently discarded. Change the repo, then run `~/bin/rebuild`. A
changed skill or command is used only after the rebuild.

- `sed`, `find`, `stat` and `date` on PATH are GNU (nix), on macOS too. Use
  `sed -i 's/a/b/' file`, never `sed -i ''`. Prefer the Edit tool for file edits.
- Your Bash cwd starts at the session's working directory and persists between
  calls in a main session. Do not prefix commands with `cd` into that same
  directory. A subagent's cwd resets before every call.
- Update `MEMORY.md` with the Edit tool, not a shell `>>` redirect.
- Write a long file with the Write tool, not a heredoc.
