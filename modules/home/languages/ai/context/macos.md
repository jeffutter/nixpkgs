
# macOS paths

When you show me a path under `/tmp/`, write it as `/private/tmp/...`. `/tmp`
is a symlink to `/private/tmp`, and some apps cannot open the `/tmp/` form
when I paste it. This applies to every path you print for me: in prose, code
blocks, commands for me to run, and end-of-task reports. Tool calls can keep
using `/tmp/`.
