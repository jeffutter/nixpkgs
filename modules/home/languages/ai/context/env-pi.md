# Environment

`~/.pi/agent/` is generated by nix from `~/.config/home-manager` — see
`modules/home/languages/ai.nix`. `AGENTS.md`, `settings.json`, `models.json`,
and `extensions/` are read-only `/nix/store` symlinks, so editing them in place
fails or is silently discarded. Change the repo, then run `~/bin/rebuild`.

Skills are loaded from `~/.claude/skills` via the `skills` setting — that path
is shared between harnesses, not Claude-only, and is generated from
`modules/home/languages/ai/skills/`.
