# <Title> (narrated presentation)

Output: `out/<name>.mp4` and `out/<name>.srt`. The caption track is soft and off by default.

| Path | What it is |
|------|------------|
| `research/`, `outline.md`, `plans/` | Research notes with sources, the outline, per-part plans |
| `script.md` | Source of truth: per scene the medium, visual spec, voice and narration |
| `say.json` | TTS spellings applied to captions |
| `music.json` | The music take and the cut for each music scene |
| `scenes.json` | Generated by `present scenes`; do not edit |
| `visuals-src/` | One script per scene; `_bumper.py` holds the title card, bumpers and outro |
| `audio/narration/`, `visuals/`, `music/*.wav`, `out/` | Generated media, untracked |

## Recompose after a change

```sh
present scenes                      # script.md -> scenes.json
present video voice scenes.json     # re-voices changed scenes only
present stt-check <id>              # pronunciation against the script
present render-all                  # re-times every scene from its clip
present scenes                      # picks up new mp4 visuals
present music                       # music scenes and beds (after voice and visuals)
present video assemble scenes.json out/<name>.mp4
present video check out/<name>.mp4
```

`present video frame visuals/<id>.mp4 <sec> /tmp/f.png` extracts a frame. `present` is the narrated-presentation skill's tool.
